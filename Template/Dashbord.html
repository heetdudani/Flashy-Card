What is the difference between let and const in JavaScript?

JavaScript Basics Back

let allows you to declare variables that can be reassigned: 

let counter = 0;
              counter = 1; // Valid

const creates a read-only reference to a value (but the value itself can still be mutable if it's an object or array): 

const PI = 3.14159;
                PI = 4; // Error!
                
                const user = { name: 'John' };
                user.name = 'Jane'; // Valid
